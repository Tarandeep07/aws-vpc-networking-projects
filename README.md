## About This Repository

This repository documents a hands-on learning journey focused on **Amazon VPC and AWS networking** through a structured series of nine practical projects.

The projects progressively explore the architecture and management of cloud networks, starting with the fundamentals of VPC creation and IP addressing and progressing toward traffic control, private networking, connectivity, monitoring, VPC peering, S3 integration, and VPC endpoints.

Rather than focusing only on theoretical concepts, this portfolio emphasizes **practical AWS infrastructure configuration, networking fundamentals, security controls, troubleshooting, and technical documentation**.

Each project contains implementation evidence, architecture diagrams, configuration details, AWS CLI commands, key concepts, challenges encountered, and lessons learned.

## Documentation Philosophy

This repository is intended to document **hands-on implementation**, not simply reproduce tutorial instructions.

For each project, I document:

* What was implemented
* Why each networking component was required
* How the components interact
* Relevant AWS configuration
* Network traffic behavior
* Security considerations
* Problems encountered during implementation
* How issues were resolved
* Key technical concepts learned

Screenshots and architecture diagrams provide supporting evidence for the documented implementation.

---

## Security & Credential Handling

This repository intentionally does not contain:

* AWS access keys
* AWS secret keys
* Session tokens
* Passwords
* Private keys
* `.pem` files
* Other authentication credentials

AWS resource identifiers may be represented using placeholders where appropriate.

All AWS credentials are kept outside the repository and are **never committed to Git**.
